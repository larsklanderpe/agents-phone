What .NET 6 is for

The bi-directional worker on its bidirectional branch targets .NET 5, not 6. A .NET 6 runtime does not run a .NET 5 build by default. If the worker is the reason for the 6 hop, it needs a retarget or a roll-forward setting. If something else needs 6, the book should name it.
